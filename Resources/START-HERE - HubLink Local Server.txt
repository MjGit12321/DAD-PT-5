HUBLINK LOCAL SERVICE - PERFORMANCE TASK 5

This package runs the instructor-provided shipment API on your own Windows
x64 computer. The .NET runtime needed by this service is included. You do not
need the classroom LAN, Postman, or the API source code to run the service.
The shipment data is fictional and resets to the same fixed records on restart.

1. Extract the ENTIRE ZIP to a normal folder. Do not run files from inside the
   ZIP preview. Keep HubLink-Service next to the two Start files.
2. Double-click Start-HubLink.cmd. Keep its window open while using the API.
3. In a browser, open:

   http://127.0.0.1:5080/api/shipments?branchCode=BR-001

   You should see a JSON response with five BR-001 shipments. In your desktop
   client, use http://127.0.0.1:5080 as the service base address and BR-001
   as the branch. The response is generated by the program on YOUR computer.
4. When finished, close the service window or press Ctrl+C in that window.

IF PORT 5080 IS ALREADY IN USE

Close the unsuccessful service window and double-click
Start-HubLink-5081.cmd instead. Then replace 5080 with 5081 in the browser
URL and your application's service base address. Run only one copy of this
package at a time. A port conflict can also mean another service is already
using that port; do not stop a process unless you know what it is.

TESTING

Both the normal endpoint and the separate controlled test endpoint are
included. See HubLink-Student-API-Reference.md for branch identifiers,
request paths and modes such as empty results, errors, invalid JSON and delay.
The optional PowerShell guide shows how to inspect responses without Postman.
Stopping the local service provides a way to test an unreachable service.

IMPORTANT DETAILS

- This package is for Windows x64. The executable binds only to 127.0.0.1,
  so each computer must run its own copy; it is not a shared LAN server.
- The service works without internet after the complete package is downloaded
  and extracted. Building your own desktop client may still require downloads
  for its SDK and packages.
- Students use the supplied API; modifying or developing its server code is
  not a graded requirement.
- If the program cannot start, confirm the ZIP was fully extracted, the start
  files and HubLink-Service folder remain together, and Windows is 64-bit. If both ports
  are occupied or an error persists, share the exact error with the instructor.
